下划线的几种 CSS 实现方案

发表于 2025-02-19 分类于 笔记 ， 前端

起因只是想为博客的超链接美化一下样式，却不慎跌入了下划线的大坑。在折腾了好几种方法但效果都不尽如人意后，我发现还是基本的 CSS 属性效果最好（真香）。

text-decoration

2025 年的今天，似乎不需要考虑兼容性问题了，吗？

CSS 官方的装饰线属性，先来看看兼容性如何~

看起来除了 Safari，在多端上表现都良好。等等，“included in shorthand”？有些不对，再看看。

原来这里的 text-decoration-thickness 属性在 Safari 上只是对简写不太支持，单独一条的写法是完全没问题的！因此实际使用时，为了保证兼容性，我建议还是分开写这些属性。

text-decoration 和 border 类似，实际是由三条（排除 thickness）属性构成的简写，分别是：

  • text-decoration-color
  • text-decoration-style
  • text-decoration-line

color 属性，略。

style 属性，决定了装饰线的外观。支持 solid、dotted、dashed、double 和 wavy （波浪线），可基本满足我们的需求。

而 line 属性，则决定了装饰线的类型（或位置），除了常规的 underline、none，还支持设置为 overline 上划线和 line-through 中划线，当然也没什么机会用就是了。

thickness 属性，用于配置装饰线的厚度，默认为 auto，可以设置为特定长度值，也可设为百分比值；设为百分比时，会根据当前字号大小来计算厚度，最小 1px。

/* length */
text-decoration-thickness: 0.1em;

/* percentage */
text-decoration-thickness: 10%;

这里直接借用 chokcoco 老师的图展示一下各个属性的效果：

除了以上这些属性，还有一个 text-underline-offset 也值得一提。该属性用于设置下划线相对其原始位置的偏移量，取值和 thickness 一样为特定值或百分比；而且它只影响值为 underline 的装饰线，并不会影响其它装饰线的偏移量。

多个装饰线

text-decoration-line 是支持同时配置多个的，具体写法如下：

text-decoration-line: overline underline line-through;

但可惜的是，除此之外的其它属性并不能同时指定多种线的样式。只能通过嵌套多个元素的方式给分别插入装饰线并添加相应样式（所以光它一个厉害其实没什么用）。

<p>
  Lorem Ipsum is 
  <span classname='u'><span classname='lt'> simply dummy text </span></span> 
  of the printing and typesetting industry.
</p>
u {
  text-decoration-line: underline;
  text-decoration-color: red;
}

lt {
  text-decoration-line: line-through;
  text-decoration-color: lime;
}

过渡效果

text-decoration 每个值都可以触发过渡效果，我们可以以此实现一个超链接 hover 样式。

由于 thickness 并不支持设置为 0px，所以考虑设置通常状态下 color 为 transparent，并在 hover 状态下调整颜色；最后调整一下 offset 偏移和 thickness，一个简单的下划线过渡动画就完成了。

a {
  text-decoration: underline solid transparent;
  text-underline-offset: 6px;
  text-decoration-thickness: 1px;
  transition: all 0.2s linear;
  cursor: pointer;

  &:hover {
    text-decoration: underline solid $post-link-color;
    text-underline-offset: 4px;
    color: purple;
  }
}

border

效果一般的实现方式，本来就是因为 text-decoration 兼容性问题才使用的替代方案，可以的话尽量不用。代码本身没什么好说的，至多就是和伪元素结合使用。

a::after {
  content: "";
  position: absolute;
  left: 0;
  right: 0;
  height: 0;
  bottom: 0;
  border-bottom: 1px solid black;
}

只用 border 方式实现的下划线要通过 padding 来控制文字间距，并且由于 border 本身参与盒子模型计算，会对整体样式产生一定影响；同时它对于 block 类型的多行文本效果也不好（无论用不用伪元素），这种情况下只展示最后一行的下划线，看起来非常奇怪。

box-shadow

和 border 类似，相比 border 好处是不会影响布局，但是坏处是只能实线样式，没有其它花活，且不方便调整间距，得用多个 box-shadow 重叠处理。

a {
  box-shadow: 0 1px 0 0 #ccc;
}

background

background 的花活就很多了，这里只介绍最简单的下划线，其实就是利用 linear-gradient 模拟实线或虚线；过渡效果等更多技巧可看 chokcoco 老师的文章，也是使用 background-size 和 background-position 来实现的。

a {
  background: linear-gradient(90deg, #ccc, #ccc);
  background-size: 100% 1px;
  background-repeat: no-repeat;
  background-position: 100% 100%;
}

scaleX 实现过渡效果

缺少泛用性，需要实现某些特殊效果时，可以考虑

配合伪元素和 transition 实现一个 hover 从中间向两边展开下划线的效果：

a {
  position: relative;
  cursor: pointer;
      
  &::before {
    background: purple;
    bottom: 0;
    content: '';
    height: 2px;
    position: absolute;
    width: 100%;
    transform: scaleX(0);
    transition: transform .2s;
  }
  
  &:hover {
    color: purple;

    &::before{
      transform: scaleX(1);
    }
  }
}
