GitHub Pages 国内访问加速

发表于 2024-12-17 分类于 笔记 ， 博客搭建

GitHub 访问目前在大陆地区基本上是半通半堵的状态，而通过 GitHub Pages 部署的博客，访问速度同样极其受限。根据当前测试的结果，如果不做任何处理，大陆地区单是获取 HTML 文件就要去到十几秒的样子，加上字体、图片等其它较大的资源加载时间，体感直接回到 ADSL 时代。

经过网络检索和亲自实践后，我整理了一份 GitHub Pages 站点可用的加速方案，仅供参考。

Cloudflare 加速域名

放心，Cloudflare 加速是免费的，只要创建一个账号就能用了。
加速前提是有自己的域名并且已经在 GitHub Pages 上设置好了 CNAME 映射，具体配置不再赘述，见 GitHub 自定义域名的配置方式

原理：CDN 加速将静态资源提前下载并缓存在边缘节点；我们通过 Cloudflare 通道加载部署在 GitHub 上的静态资源，可以解决直接访问 GitHub 不通的问题，同时进行资源的缓存。

调整域名解析地址

首先在 Cloudflare 上添加域名，网站贴心的提供了傻瓜式的流程，选择免费套餐，按部就班操作即可。Cloudflare 还会自动读取域名已有的 DNS 配置，无需再重新配置，这点比较智能（suki!）。

选择好套餐后，会提供两个新的 nameserver 地址，我们需要到购买域名的服务商那里调整域名配置，这里以阿里云举例；调整完后需要一段时间才会生效，可以通过 Cloudflare 自带的检查确认。

注意，修改 nameserver 以后，就在 Cloudflare 上进行 DNS 配置了，原来的域名提供商上的配置是无效的（一般也会有提示）

配置 HTTPS

Cloudflare 提供了免费的 HTTPS 证书，类似 GitHub 强制 HTTPS，这个一般看情况配置。

注意，如果选择灵活模式，那么 Cloudflare 和 Github Pages 之间的通信是 HTTP， 如果你在 Github Pages 中开启了强制 HTTPS，就会出现无限重定向的问题。

如果你的域名只用于博客，这种情况可以设置成完全，保持两边使用的协议一致即可。但是如果你像我一样，其中一个子域名（blog.xxx）作为博客网址，还有其它的子域名，可以参照如下配置，仅对博客的站点进行 HTTPS 处理。

域名的 SSL/TLS 加密依旧选择灵活模式，保持浏览器到 Cloudflare 是 HTTPS，Cloudflare 到源服务器是 HTTP。

配置 规则 > Configuration Rules ，创建一条规则，针对博客的子域名开启完全模式并保存，稍后即会生效。

手工配置 CDN

以上的加速方式仅适用于存放在 GitHub 站点上的静态文件，对于博客用到的一些额外的 JS 插件、字体或是图片类的内容，包括我们给博客添加的一些花里胡哨的玩意，则可能还需要用其它方法加速。

博客配置

鉴于博客部署种类过多，此处仅用 Hexo + NexT 主题举例。可参照自己的部署方案去查看是否有相应配置

NexT 主题对于插件（无论官方或第三方）都是可以配置 CDN 的，具体在 _config.next.yml 文件下 vendors 有相应说明

# See: https://theme-next.js.org/docs/advanced-settings/vendors
vendors:
  # The CDN provider of NexT internal scripts.
  internal: custom
  # The default CDN provider of third-party plugins.
  plugins: custom
  # Custom CDN URL
  custom_cdn_url: https://cdnjs.cloudflare.com/ajax/libs/${cdnjs_name}/${version}/${cdnjs_file}

除此之外，如果手动引入一些小玩意（比如 JS 脚本、CSS 文件等），尽量不要放到 header.njk 文件下，可以像我一样放到 footer.njk 去，这样不会阻塞常规内容的加载。同时这些 import 的资源也可以上 CDN 加速，这个太简单了就用不多说了。

图片加速

博客文章中的图片一般都放在图床上，如果是国内的图床，影响不大。如果像我一样放在 GitHub 上，可以通过 jsDelivr 的服务进行加速。但又因为 jsDelivr 在大陆也属于鼻炎患者——一边通一边塞，所以我这里改用镜像站 jsd.cdn.zzko.cn

做法就是将图片资源的路径修改为镜像站的域名，用法和 jsDelivr 一样。
路径格式： https://jsd.cdn.zzko.cn/gh/[username]/[reponame@branch]/[filepath]

后续：又发现了新的方法，如果 CDN 加速不稳定，可以使用 Cloudflare 反代 GitHub 仓库加速，参考：使用 github 私有仓库和 Cloudflare Workers 搭建个人图床

结语

以上一套操作下来，基本上国内的访问就没什么问题了。还想要继续优化的话，还可以从博客部署本身入手，比如对代码、图片进行压缩之类的。
